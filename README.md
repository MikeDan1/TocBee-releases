# TocBee – Downloads

TocBee ist eine Desktop-App für macOS, mit der du Meetings vorbereitest, mit Timer durchführst und das Protokoll direkt mitschreibst.

Dieses Repository enthält **nur die fertigen Downloads und Updates**. Der Quellcode ist nicht öffentlich.

## ⬇️ Download

**[TocBee.dmg herunterladen](https://github.com/MikeDan1/TocBee-releases/releases/latest/download/TocBee.dmg)** – zeigt immer auf die neueste Version.

Alle Versionen und Änderungen: [Releases](https://github.com/MikeDan1/TocBee-releases/releases)

## Installieren

1. `TocBee.dmg` öffnen und **TocBee** in den Ordner **Programme** ziehen.
2. Beim ersten Start einmalig freigeben: **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** (bis macOS 14: Rechtsklick → Öffnen).

Voraussetzung: Mac mit Apple-Chip (M1 oder neuer). Die Kurzanleitung liegt als PDF in der DMG.

## Updates

Ab Version 1.2.0 findet TocBee neue Versionen selbst und installiert sie mit einem Klick («Jetzt aktualisieren» in der Seitenleiste).
