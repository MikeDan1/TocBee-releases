# TocBee – Downloads

TocBee ist eine Desktop-App für macOS, mit der du Meetings vorbereitest, mit Timer durchführst und das Protokoll direkt mitschreibst.

Dieses Repository enthält **nur die fertigen Downloads und Updates**. Der Quellcode ist nicht öffentlich.

## Installieren

1. Unter **[Releases](https://github.com/MikeDan1/TocBee-releases/releases/latest)** die Datei `TocBee-<Version>-arm64.dmg` herunterladen.
2. DMG öffnen und **TocBee** in den Ordner **Programme** ziehen.
3. Beim ersten Start einmalig freigeben: **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** (bis macOS 14: Rechtsklick → Öffnen).

Voraussetzung: Mac mit Apple-Chip (M1 oder neuer).

## Updates

Ab Version 1.2.0 findet TocBee neue Versionen selbst und installiert sie mit einem Klick («Jetzt aktualisieren» in der Seitenleiste).

Die Kurzanleitung liegt als PDF in jeder DMG.
